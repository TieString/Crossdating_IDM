## 记录标准

以下情况应新增或更新本目录文档：

1. 依赖升级导致运行行为变化。
2. Tauri sidecar、文件系统权限或窗口桥接出现非显然问题。
3. COFECHA、RWL 解析、保存格式、持久化格式出现会影响数据安全的问题。
4. 问题需要特殊恢复步骤，不能只靠代码 diff 理解。
5. 同类问题未来很可能再次发生。
