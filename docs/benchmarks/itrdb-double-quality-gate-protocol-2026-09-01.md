# ITRDB 双重质量门槛协议

统一诊断模型的正常阳性测试同时约束文件质量和目标序列质量。文件相关性只用于定义数据档位，不能替代目标序列自身的可辨识性检查。

## 冻结资格

- 干净 RWL 文件的内部相关性必须属于 `0.60-0.70`、`0.70-0.80` 或 `>=0.80`。
- 文件的 COFECHA possible problem segments 必须为 0。
- 目标序列在干净状态下与 leave-one-target-out master 的相关性必须 `>=0.60`。
- 目标序列的 COFECHA A 问题段必须为 0，且不含自然 0。
- 目标序列长度至少 100 年；场景生成后旧侧至少保留 45 年、新侧至少保留 15 年。
- 排除当前目标后，至少保留 5 条满足同一干净资格的参考芯。

不满足任一条件的目标不会进入场景生成、训练或测试分母。场景仍按完整 RWL 文件隔离，相关性档、目标相关性档、长度、事件位置、事件数量和参考深度分别报告。

## 现有 External50 的处理

现有 External50 已冻结，不能重选案例。其目标序列均已满足目标级 `masterCorrelation >=0.60`、A 问题段为 0、自然 0 为 0和参考深度门槛；其中两个文件的文件级内部相关性低于 0.60。它们保留在原始审计文件中，但不进入当前三档正式指标。后续全新最终留出集在冻结前直接应用本协议，不再依赖报告阶段过滤。
