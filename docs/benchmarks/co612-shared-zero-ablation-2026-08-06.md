# co612 共享 0 局部化消融（2026-08-06）

## 目的与约束

在同一组 45 条含自然 0 的样芯、358 个逐轮恢复案例上比较：

- `legacy6`：旧实现，搜索 lag 头 ±6 年；远距离 marker 可以重置主窗口中心，marker 也决定 5/7/13 年宽度。
- `none`：完全禁用共享 0。
- `local2`：生产默认，只搜索 lag 头 ±2 年；marker 只能重排窗口内年份，不能改变操作、窗口中心或宽度。

`none` 和 `local2` 的窗口宽度均只由 lag 头的 `headMeanAdvantage` 决定：`>=0.4` 为 5 年，`0.08–0.4` 为 7 年，更弱为 13 年。共享 0 的存在与数量不参与宽度决策。

## 结论

- 完全禁用共享 0 会把 Top1 从 75.98% 降到 52.23%，且重复错误峰从 29 增至 85，因此共享 0 仍有明显的局部排序价值。
- 相比旧基线，`local2` 将重复错误吸引从 39 降到 29，远距离重复吸引从 23 降到 19；旧的 1735、1685 固定峰不再进入重复吸引列表。
- 代价是主窗口覆盖率从 94.13% 降到 90.78%，Top1 下降 2.23 个百分点。旧基线的一部分额外覆盖来自远距离 marker 偶然把窗口拖向真年，不能继续作为合法定位证据。
- `local2` 达到任务门槛：主窗口覆盖率不低于 90%，中位宽度不超过 7 年，同时显著减少固定吸引并保留大部分 Top1 收益。
