## 主要结论

1. A 单事件已经稳定通过目标；最低子类是单局部移动 90.40%。
2. B 总体通过，但多个局部移动的 n3/n4 子类仅为 80.90%/84.73%，串行恢复率更低。
3. C 总体观察值超过 90%，但文件聚类下界未通过。最弱的是多个缺轮 gap5，尤其 n4：75.70%。
4. D 仍是主要短板。四类型组合只有 39.13%，整体移动与伪轮组合也只有 61.76%。
5. D 的条件窗口覆盖率仍为 93.33%，主要损失继续发生在操作/位移仲裁和前沿顺序，而不是已选正确操作后的窗口普遍失效。
6. 本轮没有生成任何正向自动整体移动，所有窗口宽度均合法，保存重开稳定率为 100%。

本轮没有运行 Clean 家族；clean 误报率应继续引用独立 clean 基准，而不能从 A/B/C/D 推导。
