# 不可变两级裁决器：External50 开发 OOF 结果（2026-08-29）

## 结论

本轮严格冻结候选生成器，只重做裁决器。操作/位移头取得了可复现提升，但同身份位置头未达到发布门槛，因此不替换生产裁决器。

- 候选 Oracle 保持 `4057/4118 = 98.52%`，没有新增候选、扩窗或修改定位规则。
- 八视图 listwise + top-2 hard-negative pair 融合的操作/位移头：
  - 严格操作 Top1：`3935/4118 = 95.56%`。
  - 可定位工作流身份 Top1：`3917/4118 = 95.12%`。
  - Clean 误报：`0/500`。
- 最佳同身份位置头最终为 `3639/4118 = 88.37%`，文件聚类单侧 95% 下界 `86.73%`。
- 零回归安全投影可做到 `正确 -> 错误 = 0`，但仅为 `3574/4118 = 86.79%`，不能作为 95% 独立模型。

External50 已用于文件级 OOF 模型选择，现属于开发集；正式替换前必须另选从未打开的完整 RWL 文件做最终留出测试。

## 冻结输入

- 50 个完整 RWL 文件，4118 次事件前沿诊断，另有 500 次 Clean。
- 冻结操作候选：75673 个身份，SHA-256 `8999f8d448a44be3f710504070463a8f1abdadc124bddec51db756d2dbcf9648`。
- 冻结位置候选：502299 个窗口包；紧凑表仍保留相同 75673 个身份和 4618 次诊断。
- 所有 OOF 均按完整 `file_id` 隔离。模型特征不包含文件名、序列名、A/B/C/D、固定年份或真值字段。
- 原始数值证据仅以诊断内 rank、z、winner margin、候选间分位数和参考芯一致性进入模型。

位置头只在操作头选定的同一 `operationType + shiftYears` 身份内排序原有窗口；操作类型和位移不可变。最佳结果来自 192 个无标签筛选证据通道的文件级 OOF listwise/pairwise 融合。

## 安全投影

保留同身份原主包、仅按 OOF 身份 margin 切换解释时：

- 未加零回归门：`3710/4118 = 90.09%`，但 `正确 -> 错误 46`。
- 校准为 `正确 -> 错误 0`：阈值 `0.470588`，只接受 16 次切换，修复 10 次，最终 `3574/4118 = 86.79%`。

该安全投影可作为 shadow 观察工具，但不能替代独立统一模型，也不能用于宣称达到 95%。

## 后续边界

本轮已验证：当前操作/位移裁决器可以跨过 95%，最终瓶颈已转移到逐年位置证据。若继续保持候选生成器完全冻结，现有位置证据的文件外排序上限明显低于候选 Oracle；继续堆阈值、扩窗、按类型或按相关性拆模型均无效。下一轮若继续提高最终准确率，应单独改进逐年证据生成与位置后验，再用新的完整文件留出集验证，不能继续在 External50 上调参。
