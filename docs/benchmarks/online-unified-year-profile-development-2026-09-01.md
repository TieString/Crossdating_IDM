# 线上统一模型逐年反事实证据实验

## 结论

在 50 个完整 RWL 文件上各冻结 1 条目标序列，构造 A/B/C/D 共 200 个案例、404 次事件机会。所有 OOF 折按完整 RWL 文件隔离。

只扩大锚点搜索半径可提高候选召回，但不能恢复完整年份分布。将已经计算的 raw、difference、combined、单侧阶跃、最小侧优势和修正侧支持保留为同身份逐年证据后，工作流候选 Oracle 达到 404/404。

| 候选方案 | 工作流候选 Oracle |
|---|---:|
| 冻结模型契约：锚点 +/-13 年 | 92.82% |
| 只加入六通道峰 | 92.82% |
| 只扩大到 +/-25 年 | 94.31% |
| 六通道峰 + +/-25 年 | 94.31% |
| 同身份完整逐年证据表 | **100.00%** |

最终窗口仍只允许 5/7/9/13 年；扩大的是模型内部逐年候选，不是 UI 窗口。

该样本用于验证证据生成方向，不用于替换模型。下一步应在完整 External50 开发集上重新生成逐年证据并训练；之后只能用全新完整 RWL 文件做最终留出验证。

## 冻结契约

- 当前应用继续使用旧模型的 +/-13 年候选和旧锚点。
- 新逐年证据、profile peaks 和扩展候选必须由匹配的新模型显式启用。
- 不使用文件名、序列名、类别标签、固定年份或真值字段作为特征。
- 操作头不能移动窗口；位置头不能修改操作或位移。
