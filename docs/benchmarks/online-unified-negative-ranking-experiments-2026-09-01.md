# 统一模型排序负结果（2026-09-01）

评估使用同一批 50 个完整 RWL 文件，并按文件执行 5 折 OOF。正式统计继续应用双重质量门槛：文件内部相关性不低于 0.60，目标序列干净态 master 相关性不低于 0.60、A 问题段为 0、自然 0 为 0，且至少有 5 条目标排除参考芯。

| 实验 | 全部 4618 次 | 主要变化 | 结论 |
|---|---:|---|---|
| 无自反馈二值基线 | 92.01% | 去除上一轮统一模型 claim | 独立能力基线 |
| 精确操作高于等价解释 | 92.53% | B 提升，Clean 略降 | 保留 |

## Top1 距离分级

把覆盖窗口按 Top1 距真值的 0、2、4、6 年距离设为不同相关性等级后，模型过度追逐精确中心，舍弃了更稳健的覆盖窗口。A/B/C/D 分别降至 90.80%、88.31%、85.57% 和 83.75%。该训练目标已经通过反向提交撤销。

## 独立操作类型头

将候选先按五种操作类型聚合、再在获胜类型内选择位移，类型头本身达到 95.37%，但最终操作/位移只有 94.72%。聚合过程损失了同位移身份之间的细节，A/B/C/D 分别为 94.60%、93.20%、93.37% 和 86.82%。该结构已经通过反向提交撤销。

当前保留方案仍是：不可变候选证据表 → 联合操作/位移头 → 同身份位置头 → 一个最终建议。整体移动候选可读取同位移 partial 的断点曲线，但不预先聚合或改写操作身份。

## 文件级 OOF 堆叠

第一层仅使用底层证据；第二层只读取第一层按完整 RWL 留出的操作、位移和窗口预测，不读取真值或正确性字段。该结构使 B 和 D 各提升约 0.08 个百分点，但 C 同时下降，整体仅从 93.22% 变为 93.24%。收益不足以抵消双模型在线推理和模型包复杂度，已经撤销。

## 生产同构候选预筛

进一步审计发现，前述约 93% 的离线导出器会额外保留真实操作身份、工作流等价身份和覆盖真年份的位置窗口；这些行的标签可用于训练，但不能决定哪些候选进入线上排序。修复后，导出器和 Tauri 共享同一个无真值预筛：每类操作保留诊断内前 12 个、全局保留前 64 个，位置只按底层证据保留前 128 个。

严格候选集的操作候选 Oracle 为 96.86%，完整工作流包 Oracle 为 95.43%。50 个文件的文件隔离 OOF 为 82.83%；应用双重质量门槛后为 3694/4455 = 82.92%，文件聚类单侧 95% 下界为 80.55%。A/B/C/D 分别为 90.42%、84.64%、81.29% 和 74.59%。操作错误 372 次、操作正确但窗口错误 389 次，另有 209 次完整工作流包 Oracle 缺失。

按文件内部相关性分层，0.60-0.70、0.70-0.80、至少 0.80 分别为 79.33%、81.60% 和 89.90%；按目标序列与 master 相关性分层，三档分别为 76.17%、83.74% 和 89.71%。因此排除目标相关性低于 0.60 的不可辨识序列是必要的质量控制，但不能解释严格线上候选下的大部分排序损失。这一模型不替换当前应用模型。
