# Figure QA notes

## Figure contract

- Core conclusion: lag topology, executable counterfactuals and multi-reference evidence jointly resolve one traceable operation, shift and focused review window.
- Archetype: portrait workflow plus compact quantitative and schematic composites.
- Backend: Python / matplotlib.
- Typography: English Times New Roman throughout.

## Statistics

- n definition: injected truth events for family and single-event panels; RWL files for file-level generalization.
- Replicate structure: RWL files are independent generalization clusters; injected scenarios within a file share that cluster.
- Center statistic: observed proportion.
- Family recovery intervals: RWL-file clustered bootstrap, 10,000 replicates.
- Single-event intervals: Wilson 95% confidence intervals.
- Generalization unit: 23 independent RWL files.
- Split: unseen-file generalization manifest with one target series per file.
- Tests/corrections/p-values: not used; panels report proportions and confidence intervals.
- Metric contract: strict recovery combines operation, shift and focused-window recovery; other rows remain separately labelled.
- Quantitative source: `docs/benchmarks/itrdb-current-generalization-result-v1.json`.
- Source tables: `source_data/*.csv`.
