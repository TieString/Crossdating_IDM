# 有效修改记录与工作区迁移

## 使用入口

- **操作记录窗口 → 导出有效修改记录**：导出 UTF-8 BOM、CRLF 换行的 CSV。Excel 可直接读取中文。按序列分组，列为序列编号、修改类型、原年份/范围、现年份/范围、原值、现值、位移量、单位和说明。
- **设置 → 工作区迁移**（在缓存管理旁）：导出当前文件工作区、导入工作区。操作在主窗口执行，格式为 `.cdworkspace`。

导出以已经应用到宽度网格的编辑器数据为准，包含未保存到RWL的修改。尚未应用的文本编辑或图表移动预览请先应用。原始RWL、扫描原图和模型不会被修改。CSV导出不删除或精简内部日志。

## 原始基线和有效修改

`RwlPersistedHistorySnapshot.comparisonBaseline` 独立保存首次工作的原始数据、格式和精度。普通保存及另存使用的磁盘基线/`rawData` 可以更新，而此对比基线不随之重置。它随历史快照持久化并进入迁移包。日志不再截断为最后500条。

CSV通过当前有效操作的前后快照重放年轮身份，再对比最终状态。插入后的附带年份变化不算成轮宽修改或独立移动；100→120→130合并为100→130，回到原值则省略。删除原轮后插入不同值保留两个操作。显式连续移动按仍存在的同一批年轮合并净位移。被撤销操作不进入当前有效结果。新增/删除/有明确映射的改名均记录。

整段文本替换、旧日志不完整等无法可靠追踪身份时，输出“区间差异（需复核）”、前后年/值数组及原因，不推断为缺轮或断裂。较大区间分块写入，避免超长Excel单元格。轮宽数值以列出的明确单位解读；混合精度工作区内部已统一单位。

旧版快照不含独立对比基线时，会使用该快照仍保留的原始数据，并在CSV中标明 `legacy-snapshot`。旧版已经重置的基线或已截断的历史无法从当前RWL凭空恢复。

## 包契约 v1

标准ZIP容器，仅允许两个根级条目：

```text
manifest.json
workspace.json
```

`workspace.json` 是恢复的唯一数据来源，包含当前和原始RWL数据、独立对比基线、当前/原始精度及混合终止符信息、删除标记及原值/分配量、按序列保存的完整有效操作日志和计数器、必要手动参考配置及扫描校准信息。Map序列化为数组，年和值必须为安全整数（缺测可为null）。原始零宽与新增零宽由基线及操作来源区分。

`manifest.json` 记录 `CrossdatingWorkspace` 格式名、包版本、应用版本、导出时间、源文件名、workspace.json的SHA-256、由包内当前/基线数据序列化得到的RWL文本SHA-256，以及两者的内容身份SHA-256。文本哈希针对规范导出的RWL字节；内容身份忽略路径、空白和记录排序，按统一物理单位比较序列/年份/宽度。无损改变格式精度仍能匹配。

不携带模型、影像缓存或COFECHA报告。扫描图片只保留SHA-256指纹，移除原电脑路径。标注、裁切、旋转、校准时轮宽和日志序号均保留。重新选择同名影像文件夹后，只有图片内容指纹匹配才关联旧标注；不匹配时标注仍保留，但不应用到另一张图片。

## 导入流程

1. 解析ZIP，拒绝多余、重复、路径型条目，检查版本、展开大小、SHA-256以及数据/日志/计数器/标注结构。通过后再询问用户。
2. 当前有未保存数据时，必须先导出当前工作区备份，或者取消。确认期间若当前编辑器变化，则拒绝覆盖并要求重新导入。
3. 选择目标RWL，按内容身份明确报告匹配“原始基线”“当前版本”或“两者一致”。不匹配时允许重新选文件，或将包内当前版另存为**尚不存在的新RWL**。
4. 用户确认替换一套完整状态。包内路径不会成为读写/删除指令。导入已有RWL时不改写该RWL；包内当前版与目标基线不同会作为未保存草稿保留。
5. 先用临时文件和原子替换持久化一份完整历史/参考/扫描上下文，再替换主编辑器。重复导入是替换，不能叠加日志。写入失败不激活新编辑器，旧持久化快照仍保留。
6. 主窗口、宽度网格、图表和操作记录统一读取新编辑器。清空旧诊断与报告状态，按当前RWL重新验证COFECHA和动态参考。

关闭重开时，完整上下文由目标电脑目标文件路径下的历史快照恢复。若目标RWL是原始基线且尚未保存包内修改，再次打开会按既有草稿协议提示是否保留未保存编辑。

## 边界

- v1迁移支持Tucson短/长格式及混合999/-9999精度；其他输入格式明确拒绝。
- 压缩包上限64 MiB，workspace.json展开上限256 MiB；超限会提示，不截断日志或数据。
- Ctrl+Z/Ctrl+Y的内存分支栈沿用现有关闭重开行为，不作为迁移内容；操作记录保留每条前后快照，可撤销符合条件的记录并恢复删除标记。
- 未保存且尚未应用的文本编辑、临时图表偏移、影像原图本体不在包内。带标注导出需要可访问的原图或已有指纹；已经改变的原图不能静默绑定旧标注。
- 本次验证覆盖契约、编辑器、持久化及窗口入口的自动化测试，未进行两台实体电脑的原生GUI操作测试。
