## 结论

本轮只评估和修改 TypeScript/JavaScript 内部诊断。三个 Python 模型没有参与打分、排序或阈值选择，当前 UI 也不显示 Python 建议。

当前产品契约已经收紧为：

- 每个独立事件只输出一个操作类型和一个主窗口。
- 不向 UI 输出或展示操作备选、位置备选，也不使用备选补足准确率。
- 当前单位缺轮和伪轮只输出一个动态 5/7/9/13 年主窗口。学习定位器先选择唯一 9/13 年模式；只有独立物理定位窗完整落在已通过安全门的 9 年窗内时才允许缩到 7 年，5 年还必须通过事件特异的高 margin 门。13 年困难案例不直接缩窄。局部移动继续保留原有路径，本轮暂不修改或评估。
- 缺轮和伪轮主窗口内保留逐年证据排序；局部移动只向 UI 输出一个首选 `firstFixedYear` 和一个 `shiftYears`，不展示内部位移或断点备选。
- 局部移动内部联合搜索 `-2..-100`，`-1` 仍由缺轮表达，正向位移不得成为自动建议。
- 多事件 case 可以输出多个彼此独立的事件；“单主窗口”指每个事件只有一个窗口，不是整条序列只能报一个事件。

最新文件互斥 validation 回归每类 86 例：缺轮唯一主窗口覆盖 `78/86=90.70%`，响应 `84/86=97.67%`；伪轮覆盖 `76/86=88.37%`，响应 `82/86=95.35%`。正式干净负例误报为 `0/86`。缺轮宽度分布为 `5:3 / 7:6 / 9:36 / 13:39`，中位 9 年；伪轮为 `5:4 / 7:1 / 9:22 / 13:55`，中位 13 年。精确 Top1 仍只有 19.77%/25.58%，因此当前版本可缩小人工复核范围，但不能解释为自动找准精确年份。

另一个未参与本轮规则选择的 43 例/类型保留分组中，缺轮覆盖 `37/43=86.05%`、伪轮覆盖 `38/43=88.37%`，两类响应率均为 `41/43=95.35%`，正式干净误报为 `0/43`；两类中位宽度均为 13 年。这说明响应率和正式干净误报已经受控，但“每类唯一主窗口覆盖 90%”尚未跨分组达成，尤其不能用前一块缺轮 90.70% 或更早固定回归的较高数字替代泛化结论。

生产规则冻结后曾运行一次的 18 文件独立留出中，排除 1 个注入前已异常样芯后正式分母为 17：缺轮响应 15/17=88.24%、覆盖 14/17=82.35%、已回答覆盖 93.33%，伪轮响应 15/17=88.24%、覆盖 15/17=88.24%、已回答覆盖 100%。正式干净误报为 0/17；保留被排除样芯时为 1/18=5.56%。在本轮已冻结的短窗规则上做生产路径复查时，6 个 9 年窗缩为 5/7 年且 6/6 保持覆盖，响应、Top1、Top3 和误报均不变；缺轮宽度分布为 `5:1 / 7:1 / 9:5 / 13:8`，伪轮为 `5:1 / 7:3 / 9:4 / 13:7`。该小留出已经消费，复查结果不得再称为 untouched，也不得用于调参。

混合事件当前不作为本轮发布门槛。最新严格训练实验包含局部移动和整体移动场景，整体事件召回/精度只有 57.6%/73.8%；这部分在完成单位缺轮和伪轮后必须重新基准和改进，不能沿用旧实验的较高数字。

当前版本适合作为窄窗口人工复核工具，不适合作为无人确认的自动修复器。

## 选择与应用

用户只面对一个主建议：

1. 查看一个主窗口；局部移动同时显示唯一首选断点和位移量。
2. 缺轮或伪轮可在窗口内选择具体年份；局部移动直接使用最终 `firstFixedYear`。
3. 查看将要执行的编辑预览。
4. 二次确认后应用。

| 事件 | 选择年份后的操作 |
| --- | --- |
| 缺轮 | 在所选年插入缺轮；所选年及较老侧向老年份移动 1 年 |
| 伪轮 | 删除所选年；较老侧向新年份移动 1 年 |
| 局部移动 | `firstFixedYear` 起保持不动，只把前一年及更老侧按唯一负向 `shiftYears` 移动 |
| 整体移动 | 仅应用已经通过整序列证据门的整体偏移 |

所有操作复用 `RwlEditor` 的撤销栈和统一操作日志。一次只应用一个事件；应用后旧诊断立即 stale，并基于当前 working series 重新诊断。

折线图的自动建议预览只消费最终事件，不生成位移菜单。手工片段移动属于独立编辑工具，不参与自动诊断的 99 个内部假设。

## 正式采样

正式基准从 `D:\软件测试\数据\ITRDB\itrdb_download\measurements` 读取数据。

- 目标序列按长度、非零年数、日历跨度和稳定顺序选择。
- 参考序列只按日历重叠选择，不按相关系数挑选容易的参考。
- 注入年份在 `olderEdge`、`olderInterior`、`middle`、`newerInterior`、`newerEdge` 五个日历位置分层轮换。
- 年份只由稳定 hash、案例编号和可用日历边界决定，不读取宽度值、局部相关性、候选分数或诊断输出。
- 选年后才测量局部信号强弱；信号不能反过来影响样本选择。
- 正式单事件基准使用原本无 0 的目标序列。原文件已有 0 的真实缺轮另设专家记录基准。
- `pickExploratoryStrongSignalYear` 只允许用于明确标注的探索性上限实验，不得进入正式准确率。
- 采样回归测试使用年份相同、宽度完全不同的序列，锁定正式注入年份必须保持一致。

offset 0–12 已用于开发和回归。offset 13–24 均已消费，不得再次把它们当作独立留出。

## 指标口径

| 指标 | 定义 |
| --- | --- |
| 响应率 | 含真事件的 case 中输出该类型主事件的比例 |
| 拒答率 | `1 - 响应率` |
| 操作准确率 | 主事件操作正确；局部移动还要求位移量正确 |
| 主窗口覆盖 | 最高证据主事件的唯一主窗口包含真年份 |
| 精确 Top1 | 最高证据主事件排序第一年等于真年份，未响应和漏窗均计失败 |
| Top1±1 | 排序第一年与真年份相差不超过 1 年，未响应和漏窗均计失败 |
| 联合命中 | 局部移动的位移量正确且唯一主窗口包含真边界 |
| 精度 | 严格一对一匹配的正确预测数除以全部预测数 |
| 完整 case | case 中所有真事件都被一对一匹配且没有额外预测 |
| 干净误报率 | 未注入问题的 case 中输出任一事件的比例 |

正式指标不读取 `locationAlternatives`、`operationAlternatives`，也不使用多窗口并集。

## 性能

正式单主窗口模式跳过最终不会显示的位置/操作备选及补充验证，并把 local-raw/paired-core 的早返回提前到昂贵上下文构建之前。操作恢复在后台验证前三个高分假设，随后只保留证据最高的一个；这不会生成 UI 备选。

## 发布判断

可以作为实验性的人工复核增强版使用，但必须保留以下边界：

- 可以报告当前三组冻结回归的缺轮和伪轮唯一主窗口覆盖均达到 0.9，但不能宣称 untouched 新文件已有同样保证。

- 不得把 `probabilityLike` 或证据分数解释为后验概率。
- 不得默认自动应用 Top1。
- 必须让用户选择年份、查看编辑预览并二次确认。
- 本轮不发布任何局部移动准确率结论，局部移动留到单位事件窗口稳定后单独处理。
- validation、reserved、holdout-v3 及 offset 13–24 均已消费，后续独立验证必须使用新的冻结分片。
