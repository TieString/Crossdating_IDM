## 结论

本轮只评估和修改 TypeScript/JavaScript 内部诊断。三个 Python 模型没有参与打分、排序或阈值选择，当前 UI 也不显示 Python 建议。

当前产品契约已经收紧为：

- 每个独立事件只输出一个操作类型和一个主窗口。
- 不向 UI 输出或展示操作备选、位置备选，也不使用备选补足准确率。
- 缺轮主窗口通常为 7 年；伪轮通常为 6–7 年；局部移动通常为 7–9 年。只有证据不足的保守回退才保留更宽窗口，默认核查扩展为 0 年。
- 缺轮和伪轮主窗口内保留逐年证据排序；局部移动只向 UI 输出一个首选 `firstFixedYear` 和一个 `shiftYears`，不展示内部位移或断点备选。
- 局部移动内部联合搜索 `-2..-100`，`-1` 仍由缺轮表达，正向位移不得成为自动建议。
- 多事件 case 可以输出多个彼此独立的事件；“单主窗口”指每个事件只有一个窗口，不是整条序列只能报一个事件。

在任意日历位置的 offset 0–12 正式开发基准中，单主窗口覆盖为缺轮 72.6%、伪轮 74.2%、局部移动 77.8%；精确 Top1 分别只有 23.7%、26.5%、51.1%。200 个 ITRDB 原始单零值样芯的缺轮主窗口覆盖为 67.5%。这些结果没有达到 0.9，不能包装成自动精确定位。

混合事件严格一对一召回在训练/独立站点为 83.3%/89.4%，达到 0.8 的事件级目标；但完整 case 识别率为 60.0%/83.3%，相邻缺轮与伪轮仍明显不稳定。

当前版本适合作为窄窗口人工复核工具，不适合作为无人确认的自动修复器。

## 选择与应用

用户只面对一个主建议：

1. 查看一个主窗口；局部移动同时显示唯一首选断点和位移量。
2. 缺轮或伪轮可在窗口内选择具体年份；局部移动直接使用最终 `firstFixedYear`。
3. 查看将要执行的编辑预览。
4. 二次确认后应用。

| 事件 | 选择年份后的操作 |
| --- | --- |
| 缺轮 | 在所选年插入缺轮；所选年及较老侧向老年份移动 1 年 |
| 伪轮 | 删除所选年；较老侧向新年份移动 1 年 |
| 局部移动 | `firstFixedYear` 起保持不动，只把前一年及更老侧按唯一负向 `shiftYears` 移动 |
| 整体移动 | 仅应用已经通过整序列证据门的整体偏移 |

所有操作复用 `RwlEditor` 的撤销栈和统一操作日志。一次只应用一个事件；应用后旧诊断立即 stale，并基于当前 working series 重新诊断。

折线图的自动建议预览只消费最终事件，不生成位移菜单。手工片段移动属于独立编辑工具，不参与自动诊断的 99 个内部假设。

## 正式采样

正式基准从 `D:\软件测试\数据\ITRDB\itrdb_download\measurements` 读取数据。

- 目标序列按长度、非零年数、日历跨度和稳定顺序选择。
- 参考序列只按日历重叠选择，不按相关系数挑选容易的参考。
- 注入年份在 `olderEdge`、`olderInterior`、`middle`、`newerInterior`、`newerEdge` 五个日历位置分层轮换。
- 年份只由稳定 hash、案例编号和可用日历边界决定，不读取宽度值、局部相关性、候选分数或诊断输出。
- 选年后才测量局部信号强弱；信号不能反过来影响样本选择。
- 正式单事件基准使用原本无 0 的目标序列。原文件已有 0 的真实缺轮另设专家记录基准。
- `pickExploratoryStrongSignalYear` 只允许用于明确标注的探索性上限实验，不得进入正式准确率。
- 采样回归测试使用年份相同、宽度完全不同的序列，锁定正式注入年份必须保持一致。

offset 0–12 已用于开发和回归。offset 13–24 均已消费，不得再次把它们当作独立留出。

## 指标口径

| 指标 | 定义 |
| --- | --- |
| 响应率 | 含真事件的 case 中输出该类型主事件的比例 |
| 拒答率 | `1 - 响应率` |
| 操作准确率 | 主事件操作正确；局部移动还要求位移量正确 |
| 主窗口覆盖 | 最高证据主事件的唯一主窗口包含真年份 |
| 精确 Top1 | 最高证据主事件排序第一年等于真年份，未响应和漏窗均计失败 |
| Top1±1 | 排序第一年与真年份相差不超过 1 年，未响应和漏窗均计失败 |
| 联合命中 | 局部移动的位移量正确且唯一主窗口包含真边界 |
| 精度 | 严格一对一匹配的正确预测数除以全部预测数 |
| 完整 case | case 中所有真事件都被一对一匹配且没有额外预测 |
| 干净误报率 | 未注入问题的 case 中输出任一事件的比例 |

正式指标不读取 `locationAlternatives`、`operationAlternatives`，也不使用多窗口并集。

## 单事件结果

offset 0–12 每类 325 个任意年份事件，另有 325 个干净负例：

| 类型 | case | 响应率 | 操作准确率 | 主窗口覆盖 | 精确 Top1 | Top1±1 | 平均宽度 | 中位宽度 | P90 宽度 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 缺轮 | 325 | 92.0% | 92.0% | 72.6% | 23.7% | 48.0% | 7.03 | 7 | 7 |
| 伪轮 | 325 | 92.0% | 92.0% | 74.2% | 26.5% | 47.4% | 6.68 | 7 | 7 |
| 局部移动 | 325 | 94.8% | 90.2% | 77.8% | 51.1% | 62.8% | 7.75 | 8 | 9 |

缺轮和伪轮一旦响应，主操作类型在该批中均正确。局部移动位移量在已响应 case 中正确率为 95.1%；位移量与主窗口联合命中为 77.8%。干净负例误报率为 12.6%。

这些结果说明目前的主要瓶颈不是简单拒答：三类响应率都超过 0.91；瓶颈是唯一窄窗口的位置和窗口内第一名。

接入残差定位后，缺轮/伪轮主窗口覆盖由 69.2%/71.4% 提高到 72.6%/73.2%，随后三假设操作验证、伪轮边缘收窄和严格同宽方向共识把伪轮最终覆盖提高到 74.2%，平均窗口降到 6.68 年。伪轮残差后验只有在 19 类证据中至少 6 类精确同意、且局部支持不弱于原 Top1 时才允许改排第一年；它不扩大窗口或生成第二位置。

本轮局部移动改进把后台反事实操作验证从前两个假设增至前三个，但最终仍只输出一个操作。相对上一版，局部移动主窗口覆盖由 76.6% 提高到 77.8%，严格预测精度由 76.1% 提高到 77.4%，全 case 位移量准确率由 88.9% 提高到 90.2%，精确 Top1 多 2/325；Top1±1 少 1/325。正常负例误报率保持 12.6%。

局部移动只在重复块边界或多视图边缘证据足够一致时收窄，最终平均宽度为 7.75 年、中位宽度为 8 年；证据较弱的 case 继续保留 9 年窗口。逐案例收窄检查不允许改变事件类型、位移量、Top1 或预测数量。

## 窗口宽度权衡

对 offset 0–12 做离线“最密集证据窗口”分析得到以下近似上限。它不是生产结果，只用于量化扩大窗口能换来多少覆盖：

| 固定宽度 | 缺轮覆盖 | 伪轮覆盖 | 局部移动覆盖 |
| ---: | ---: | ---: | ---: |
| 7 年 | 73.2% | 73.5% | 71.7% |
| 9 年 | 78.8% | 80.6% | 78.2% |
| 13 年 | 87.7% | 85.8% | 86.8% |
| 15 年 | 91.4% | 90.2% | 88.9% |

因此，单靠统一扩窗，要接近 0.9 通常需要约 15 年，而且局部移动仍未达到 0.9。这与“尽量窄、一眼定位”的目标冲突，所以生产默认没有采用扩窗，也没有用第二窗口补命中。

漏窗并不都在边缘外 1 年。真实缺轮漏窗的中位最近距离为 7 年，说明后续应改善事件位置证据，而不是把主窗口机械铺宽。

共有 190 个主预测，其中 135 个严格匹配；53 个已预测漏窗中，7 个距离主窗口 1 年以内，18 个距离 3 年以内，漏窗中位最近距离为 5 年。结果再次表明统一加一格不能解决主要误差。与旧版相比，该口径窗口覆盖由 69.0% 降到 67.5%，但 Top1±1 由 44.5% 升到 46.0%；任意年份注入上的提升不能直接外推到专家 0 标记案例。

整条序列移动的窗口覆盖整条序列，这是操作语义，不是局部事件扩窗。局部事件的中位主窗口仍为 7–9 年。

## 性能

正式单主窗口模式跳过最终不会显示的位置/操作备选及补充验证，并把 local-raw/paired-core 的早返回提前到昂贵上下文构建之前。操作恢复在后台验证前三个高分假设，随后只保留证据最高的一个；这不会生成 UI 备选。

本轮没有重新发布旧版与新版的精确耗时比。正式 offset 0–12 回归均完成，单个 25-case offset 的墙钟时间约为 27–56 秒；该时间包含每个 case 的三类注入和干净负例，不等于用户对单条序列的交互等待时间。

## 发布判断

可以作为实验性的人工复核增强版使用，但必须保留以下边界：

- 不得宣称主窗口覆盖或精确年份准确率达到 0.9。
- 不得用备选窗口、备选操作或扩窗后的并集补足正式准确率。
- 不得把 `probabilityLike` 或证据分数解释为后验概率。
- 不得默认自动应用 Top1。
- 必须让用户选择年份、查看编辑预览并二次确认。
- offset 13–24 已消费，后续独立验证必须使用新的冻结分片。
