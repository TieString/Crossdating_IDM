## 引用

数据来自 NOAA National Centers for Environmental Information, World Data Service for Paleoclimatology 管理的 [International Tree-Ring Data Bank (ITRDB)](https://www.ncei.noaa.gov/products/paleoclimatology/tree-ring)，访问日期为 2026-08-21。使用数据开展研究时，请同时引用各 RWL 文件头记录的原始调查者及对应研究。

文件 SHA-256 见 [`SHA256SUMS.txt`](SHA256SUMS.txt)。
