/goal
在当前项目中完整实现“贝叶斯化 Wenk 2003 插年/删年建议算法”，一次性完成算法核心、后端命令、前端调用、UI展示、测试和文档说明，不要拆成多轮，不要只做伪代码，不要留下 TODO、placeholder、mock、stub。最终功能必须能在真实序列数据上运行，输出每个候选插年/删年方案的后验概率、t-value、相关系数、编辑路径和可应用到现有手动编辑函数的建议结果。

背景与目标：
当前项目是树轮交叉定年软件，已有参考序列、样芯序列、图表显示、手动插年/删年/编辑功能。现在要新增一个“贝叶斯插删年建议”功能。它不是简单地先跑贝叶斯定年再跑 Wenk，而是把 Wenk 2003 的 N/I/M 编辑路径直接贝叶斯化，用贝叶斯后验概率计算最可信的插年和删年位置。

算法本质：
Wenk 2003 原算法：
- N = normal / identity，样本一个树轮对应参考年表一年。
- I = insert，样本缺失一年，在两个相邻样本轮之间插入一个虚拟轮，用于补偿 missing ring。
- M = merge，样本中两个相邻轮合并为一个轮，用于补偿 double ring / false ring。
- 原目标是寻找使 SSE 最小的编辑路径 τ。

本次实现的贝叶斯化版本：
- 候选方案 C = (startYear, editPath)
- editPath 由 N/I/M 组成
- 目标不是 minimize SSE，而是 maximize posterior probability
- 计算：
  logPosterior = logLikelihood + logStartYearPrior + logEditPathPrior + logPositionPrior - penalties
- 最终输出：
  P(startYear, editPath | sample, reference)
  P(insert between i and i+1 | sample, reference)
  P(merge i and i+1 | sample, reference)

3. 贝叶斯动态规划 / 候选路径搜索
实现 Wenk N/I/M 编辑路径的贝叶斯化搜索。

状态含义：
DP[i][j][k] 表示：
- 已消耗 sample 前 i 个值
- 已消耗 reference 当前片段前 j 个值
- 已使用 k 次编辑操作
- 当前状态下的候选路径集合

必须支持 startYear 扫描：
- 根据 referenceStartYear、scanStartYear、scanEndYear 确定候选起始年。
- 若未提供 scanStartYear/scanEndYear：
  - 若 sampleStartYear 存在，以 sampleStartYear ± 20 年作为默认扫描范围。
  - 若 sampleStartYear 不存在，扫描 reference 中所有满足 minOverlap 的合法位置。
- 每个 startYear 取对应 reference 片段进行 DP。
- 支持 partial overlap，但默认要求 overlap >= minOverlap。

转移操作：

N normal：
- 从 (i, j, k) 到 (i+1, j+1, k)
- value = sample[i]
- ref = referenceSegment[j]
- logLikelihood += normal_log_pdf(value - ref, sigmaNormal)
- logPrior += log(priorNoEdit)

I insert_missing_ring：
- 表示样本缺失一年，在 sample[i-1] 和 sample[i] 之间插入一个虚拟轮。
- 从 (i, j, k) 到 (i, j+1, k+1)
- 只允许 0 < i < sample.len()
- insertValue = (sample[i-1] + sample[i]) / 2.0
- logLikelihood += normal_log_pdf(insertValue - ref, sigmaInsert)
- logPrior += log(priorInsert)
- 加 position prior：
  - 若 sample[i-1] 或 sample[i] 是局部窄轮，增加 narrowRingInsertBoost
  - 若该位置位于低相关窗口附近，增加 lowCorrelationWindowBoost
  - 靠近序列边界则增加 edgeEditPenalty
- operation:
  - type = insert_missing_ring
  - sampleIndex = i
  - leftSampleIndex = i-1
  - rightSampleIndex = i
  - suggestedYear = candidateStartYear + j

M merge_double_ring：
- 表示 sample[i] 和 sample[i+1] 是疑似 double ring / false ring，需要合并。
- 从 (i, j, k) 到 (i+2, j+1, k+1)
- 只允许 i + 1 < sample.len()
- mergeValue = sample[i] + sample[i+1]
- 若当前项目的标准化序列不适合直接相加，则实现一个安全选项：
  - 默认仍按 Wenk 2003 使用相加
  - 代码中清楚隔离 mergeValue 计算函数，便于后续替换为 raw-width 合并后重标准化
- logLikelihood += normal_log_pdf(mergeValue - ref, sigmaMerge)
- logPrior += log(priorMerge)
- 加 position prior：
  - 若 sample[i] 和 sample[i+1] 都较窄，增加 narrowRingMergeBoost
  - 若该位置位于低相关窗口附近，增加 lowCorrelationWindowBoost
  - 靠近序列边界则增加 edgeEditPenalty
- operation:
  - type = merge_double_ring
  - sampleIndex = i
  - leftSampleIndex = i
  - rightSampleIndex = i+1
  - suggestedYear = candidateStartYear + j

路径约束：
- editCount <= maxEdits
- I 和 M 不允许在 minOppositeEditDistance 年内互相抵消；实现为惩罚或过滤，优先实现为惩罚，避免过度删除候选。
- 不允许连续无意义 I/M 抖动导致路径局部过拟合。
- 边界附近编辑降低可信度。
- 对每个 DP 状态保留 topK 条路径，按 logPosterior 降序保留，避免指数爆炸。
- topK 必须可配置，默认 20。
- 所有概率计算使用 log space，使用 logsumexp 做归一化，避免下溢。

4. 后验概率归一化
收集所有 startYear 下所有 retained candidates。
计算：
posteriorProbability = exp(logPosterior - logSumExp(allLogPosteriors))

必须输出：
- candidates 按 posteriorProbability 降序排序。
- bestCandidate = candidates[0]
- noEditProbability = 所有没有编辑操作的候选 posteriorProbability 之和。
- insertMarginals：
  - 对每个 insert position，累加所有包含该 insert 操作的候选 posteriorProbability。
- mergeMarginals：
  - 对每个 merge position，累加所有包含该 merge 操作的候选 posteriorProbability。
- marginal 列表按 posteriorProbability 降序排序。
- 每个 marginal 的 supportCount = 有多少候选路径支持该位置。
- 每个 marginal 的 bestCandidatePosterior = 支持该位置的最高单候选 posterior。

5. 统计指标
实现或复用：
- Pearson correlation
- t-value
- SSE
- RMSE
- localBeforeCorrelation
- localAfterCorrelation

t-value 计算：
r = correlation
N = overlap
t = r * sqrt((N - 2) / (1 - r^2))
需要处理：
- N <= 2
- r 接近 ±1
- 方差为 0

local correlation：
- 对每个编辑位置，计算编辑前后该位置附近窗口的相关性变化。
- 默认窗口半径 10 或 15。
- localBeforeCorrelation 和 localAfterCorrelation 可以为空，但不能导致崩溃。
